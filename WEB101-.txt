Discussão em Grupo (15 min)Organizar a turma em grupos de 3–4 pessoas. Cada grupo responde oralmente e um porta-voz compartilha:1. Por que praticamente todo site hoje usa HTTPS?     Dica: pense em segurança, senhas, privacidade.2. O que aconteceria se navegadores não interpretassem HTML?     Dica: veríamos o código-fonte puro?3. Qual a maior mudança da Web 1.0 para a Web 2.0?     Dica: de "só ler" para "ler e escrever".4. Como a IA pode mudar o desenvolvimento web no futuro?     Dica: criação automática de código, chatbots, personalização.     RESPOSTAS DO GRUPO1-	Todo site hoje em dia utiliza o protocolo HTTPS, pelo fator da segurança e criptografia para o próprio site, assim dessa maneira é possível proteger o usuário que irá acessar o site, e seus dados respectivamente.2-	Se os navegadores não interpretassem o código HTML, veríamos apenas o código fonte da pagina, diferente dos sites que vemos em nossos roteadores. 3-	A principal mudança da Web 1(pagina estática) para o Web 2, foi a participação do publico em relação a utilização do site, podendo colocar comentários e suas opiniões, dando poder ao usuário para se expressar ou de inserir dados.4-	Com a IA o desenvolvimento web trará bastante mudanças para o futuro, como a criação de código automática através da Inteligência artificial, os chatbots para conversar com o usuário que entrará no site e solucionar possíveis duvidas do usuário, além de uma personalização para cada usuário.
